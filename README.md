# Historical BGM holding page

This repository contains an earlier static holding page (`index.html`) and its identity asset. It does not contain the current scheduling/CRM application and should not be presented as that full system.

For the separately maintained application source, see [bgm_crm](https://github.com/rcc00n/bgm_crm). No live hosting, redirect, or production ownership is changed by this documentation. Original files remain available as historical work; archive this repository only after confirming no deployment still consumes it.

## Historical Netlify host

The Netlify publication is configured as a 410/noindex retirement response; application source remains intact. See [retirement scope, verification and rollback](docs/netlify-retirement.md). This is separate from provider-side unpublishing and does not alter another application or its DNS.
